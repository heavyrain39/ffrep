# Fruit Fly Re-Embodiment Project

공개 소개·FAQ 사이트입니다. 한국어·영어 문안과 실제 프로젝트 영상 중심으로 구성합니다.

## 문안 수정

`content/ko.json`에서 제목, 소개, FAQ 15개를 수정합니다. 질문의 `id`와 `media`는 그대로 두세요. 답변 안에서는 `[이름](https://주소)` 형태의 링크를 쓸 수 있습니다. HTML은 실행되지 않습니다.

작성자가 제공한 문장을 기준으로 사용합니다. 표현을 순화하거나 단서를 덧붙이는 등 내용 수정이 필요하면 먼저 작성자에게 제안하고 확인받습니다. 영어 문안은 `content/en.json`에 있습니다. 질문 순서와 문단 수, 링크와 미디어 ID는 두 언어에서 동일하게 유지합니다.

```sh
python scripts/build.py
python -m unittest discover -s tests -v
python -m http.server 8000 --directory _site
```

`http://localhost:8000`에서 미리 봅니다. Windows에서는 `python` 대신 `py`를 사용할 수 있습니다. `index.html`과 `_site/`는 생성물이므로 커밋하지 않습니다. 수정한 원본을 `main`에 올리면 기존 Actions가 다시 빌드합니다.

## 배포

GitHub Pages의 Source를 **GitHub Actions**로 설정합니다. `.github/workflows/pages.yml`이 빌드·검사한 `_site/`만 배포합니다. 설정 전에는 배포 단계를 건너뛰고 안내를 남깁니다.

공개 주소: https://heavyrain39.github.io/ffrep/

## 영상·이미지

- 첫 화면: 작성자가 2026-09-15 공개한 유메카 탐색 ON 영상.
- FAQ 1: 공식 MaleCNS 연결망 영상. 클릭한 뒤에만 YouTube 플레이어를 불러옵니다.
- FAQ 4: Arka_X의 Yumeka 공식 모델 소개 이미지와 제작자·배포처 링크.
- FAQ 10: 작성자가 2026-09-15 공개한 쇼키 탐색 ON 영상.

직접 만든 개념 그림은 사용하지 않습니다. 영상은 전체 화면과 원래 재생 속도를 유지한 웹 압축본이며 소리를 제거했습니다. 짧은 프로젝트 영상 두 개의 합계는 약 2.2MB여서 별도의 영상 서비스 업로드 없이 직접 재생합니다. 처음부터 MP4를 내려받거나 자동 재생하지 않습니다. 과거 공개 장면이며 실시간 대시보드나 최신 성과를 뜻하지 않습니다.

출처·권리 표시·변환 범위·파일 체크섬은 `assets/media/sources.json`에 있습니다. 3D 모델 자체는 재배포하지 않습니다. 새 미디어는 파일과 출처 기록을 함께 추가하고 빌드의 공개 허용 목록을 갱신합니다.

## 언어 선택

KO / EN을 한 번 누르면 본문, FAQ, 영상 설명, 이미지 대체 텍스트와 버튼을 함께 전환합니다. 한국어 원문은 그대로 보존하고 영어에서도 작성자의 말투와 농담을 유지합니다.

첫 표시 언어는 다음 순서로 결정합니다.

1. 링크에 지정한 `?lang=ko` 또는 `?lang=en`.
2. 방문자가 직접 선택해 브라우저에 저장한 언어.
3. 브라우저의 가장 우선하는 언어. `ko`, `ko-KR`처럼 한국어면 한국어, 그 밖에는 영어.

자동 감지 결과를 수동 선택처럼 저장하지 않습니다. 직접 고른 언어는 다음 방문에도 유지합니다. 브라우저 저장이 차단돼도 전환은 작동하며, URL에 선택한 언어가 남습니다.

번역을 페이지에 함께 담아 처음 선택하거나 토글할 때 별도 다운로드를 기다리지 않습니다. 펼친 FAQ와 재생 중인 영상·출처 플레이어는 유지합니다. 번역 로드에 문제가 생기면 기존 문안을 보존하고 다시 시도할 수 있습니다. JavaScript를 끈 경우에도 정적 한국어 페이지와 기본 FAQ·영상은 읽을 수 있습니다.

영문 확인: https://heavyrain39.github.io/ffrep/?lang=en

## 브라우저 검사

기본 빌드는 Python 표준 라이브러리만 사용합니다. 추가 브라우저 검사는 개발·CI 용도로만 Playwright를 사용하며, 웹사이트에 라이브러리를 넣지 않습니다.

```sh
python -m pip install playwright==1.57.0
python -m playwright install chromium
python scripts/check_browser.py
```

브라우저 언어, URL·저장 우선순위, 빠른 전환, 저장 차단, 문안·메타데이터·링크, FAQ와 영상 상태 보존, 모바일·데스크톱 넘침을 검사합니다. 결과와 화면 캡처는 `test-results/`에 기록합니다. 외부 YouTube 요청은 검사에서 대체하므로 실제 외부 플레이어의 재생 인증은 아닙니다.

## 공개 범위

공개 문안과 승인된 영상·이미지만 담습니다. 학습 코드, 실험 로그, 체크포인트, 세부 설정, 비공개 문서는 포함하지 않습니다. 영상 준비용 임시 워크플로와 원시 소셜 메타데이터도 정식 페이지 소스에 포함하지 않습니다.

사이트 자체의 분석·광고·추적 코드나 외부 폰트 서비스는 없습니다. 영상 출처 재생 버튼을 누르면 YouTube에 연결됩니다. 포트폴리오·제작자·원본 게시물 링크는 각 외부 사이트로 이동합니다.

## 타이포그래피 · 파비콘

3행 프로젝트명은 첨부된 **MuseoModerno**의 400 굵기, 나머지는 **SUIT**의 400–450 굵기를 사용합니다. 제목 크기는 데스크톱 24px, 모바일 20px로 유지합니다. `assets/typography.css`에서 조정합니다.

두 WOFF2 파일은 작성자가 제공한 파일과 바이트 단위로 같은 파일이며 `assets/fonts/`에서 자체 호스팅합니다. 외부 폰트 서비스를 호출하지 않습니다. 공급된 파일의 체크섬과 대응 라이선스도 보존합니다. 파비콘은 작성자가 첨부한 SVG의 도형을 그대로 사용하고, 내부 접근성 이름만 FFREP로 지정했습니다.

폰트 검사: `python scripts/check_typography.py`. 별도로 설치된 Chromium을 사용할 때는 `BROWSER_EXECUTABLE_PATH`에 실행 파일 경로를 지정합니다.
